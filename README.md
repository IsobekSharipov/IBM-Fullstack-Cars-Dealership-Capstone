# Cars Dealership - Full Stack Development Capstone Project

**Repository Name:** IBM-Fullstack-Cars-Dealership-Capstone

**Project Name:** Cars Dealership - Full Stack Development Capstone Project

## Project Description

This project is developed as part of the IBM Full Stack Software Developer Capstone Project.

The Cars Dealership application is a full-stack web application that allows users to browse car dealerships, filter dealers by state, view dealership details, register and log in, and submit customer reviews.

## Technologies Used

- React.js — Frontend
- Django — Backend
- Flask — Microservices
- Node.js — API services
- MongoDB and SQLite — Databases
- Docker and Kubernetes — Containerization and orchestration
- GitHub Actions — CI/CD
- IBM Cloud Code Engine — Deployment
